# 善驮论文工坊 v0.3.0（试用版）

一个纯本地运行的论文写作与检查工作台：选题 → 资料 → 提纲 → 分章节写作 → 引用 → 质量检查 → 版本记录 → 成稿导出，共 8 个模块，外加 1 个 AI 写作协作模块。

- **三种用法**：绿色版 EXE（双击即用）、安装版（桌面快捷方式 + 卸载入口）、纯 HTML（任意静态服务器）
- **导入现成材料**：`.bib` / `.ris` 文献、`.md` / `.txt` / `.docx` 正文、`.json` 项目，拖进窗口即可
- **多标签不打架**：同一浏览器开多个标签页时会同步并提示冲突，不会静默覆盖
- **不需要联网**（除你自己配置的 AI 接口），不上传任何内容
- 数据保存在本机浏览器 `localStorage`，可随时导出 JSON 备份

> 不想看文档、只想用：直接下载 [Releases](https://github.com/zane993/paper-lab/releases) 里的 zip，解压后双击 `善驮论文工坊.exe`。
> 遇到问题或有想法，去 [Issues](https://github.com/zane993/paper-lab/issues/new/choose) 提，模板会引导你写清环境与复现步骤。

## 三、安装与运行（四种方式，任选其一）

### 方式 A：绿色版 EXE（最省事，推荐）

1. 保持 `paper-lab` 文件夹完整（`善驮论文工坊.exe` 需要同目录的 `index.html`、`assets/`、`js/`，不能单独拷走 EXE）。
2. 双击 **`善驮论文工坊.exe`**。
3. 右下角托盘出现「论」字图标，浏览器自动打开 `http://127.0.0.1:8777/`。
4. 退出：右键托盘图标 → **退出**（直接关浏览器不会停服务）。

特性：

- 单实例：重复双击只会再开一次浏览器标签，不会起两个服务；
- 端口自动回退：8777 被占用时依次尝试 8778 / 8779 / 8780 / 8790；
- 托盘菜单：打开界面 / 复制访问地址 / 打开程序目录 / 退出；
- 控制台不弹窗（winexe），不写注册表，不留驻自启，属于绿色软件。

> 首次运行若出现「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**（EXE 未做代码签名）。

### 方式 B：安装版（有桌面图标与卸载入口）

1. 双击 **`install.bat`**。
2. 程序会被安装到 `%LOCALAPPDATA%\Programs\善驮论文工坊`，并创建：
   - 桌面快捷方式「善驮论文工坊」；
   - 开始菜单项（同一快捷方式）；
   - 「设置 → 应用 → 已安装的应用」中的卸载条目。
3. 安装完成后自动启动（不需要可加 `-NoLaunch`）。
4. 卸载：开始菜单右键卸载，或双击安装目录里的 `uninstall.bat`，或在「设置 → 应用」里卸载。

自定义安装目录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Target "D:\Apps\善驮论文工坊"
```

全程免管理员权限（只写 HKCU 与当前用户目录）。

### 方式 C：双击 `run.bat`（脚本启动，无需 EXE）

1. 双击 `run.bat`：优先用 Python 起服务，没有则用系统自带 PowerShell 起等价服务；
2. 浏览器自动打开 `http://127.0.0.1:8777/`；
3. 关闭那个最小化的命令行窗口即停止。

手动等价命令：

```powershell
cd <你的路径>\paper-lab
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1 -Open
# 可选：-Port 9000 换端口；去掉 -Open 则不打开浏览器
```

> `-ExecutionPolicy Bypass` 只作用于这一次调用，不修改系统策略。

### 方式 D：直接双击 `index.html`

可用，但不推荐作为长期使用方式：

- Chrome / Edge 下一般能正常读写 `localStorage`；
- Safari 会拒绝 `file://` 页面的本地存储，程序会提示“本机存储不可用”；
- 部分浏览器的剪贴板 API、下载行为在 `file://` 下受限。

**因此建议使用方式 A / B / C（`127.0.0.1` 属于安全上下文，功能最完整）。**

### 停止服务

- EXE / 安装版：右键托盘 → 退出；或任务管理器结束 `善驮论文工坊.exe`。
- 脚本方式：关闭最小化的服务器窗口，或在窗口内按 `Ctrl+C`。
- 若端口仍被占用：`netstat -ano | findstr :8777` 找到 PID 后 `taskkill /PID <PID> /F`。

## 四、首次使用：10 分钟走通全流程

1. 打开后在「项目总览」点 **载入示例项目**（示例文献为演示数据，正式使用务必替换）。
2. 「选题与评估」看候选题目与三方评分，点 **选为本题**；补完“研究问题/研究缺口”后可看评估完整度。
3. 「资料与文献」用生成的检索式去数据库检索，把结果 **粘贴 BibTeX**、**导出 .ris/.bib 拖进窗口**，或手工新增。
4. 「提纲与结构」选一个模板应用，调整章节顺序与目标字数（父章节字数＝子节之和，会自动同步）。
5. 「正文写作」逐节写；工具条可 **插入引用**（生成 `[@文献ID]` 标记）、插入过渡句、加图表占位。
6. 「引用与参考文献」核对编号顺序、未定义标记、未被引用文献。
7. 「质量检查」点 **重新检查**：得到五维分数与问题清单，可 **去修改 / 转待办 / 忽略**。
8. 「修改与版本」保存快照，选中两个版本可看差异并回滚。
9. 「成稿导出」先看 **导出前校验**，再选格式导出 Markdown / 独立 HTML / 纯文本，或直接打印为 PDF。

数据自动保存，`Ctrl+S` 手动保存，`Ctrl+Shift+C` 在写作页插入引用。

## 四之二、AI 写作协作（v0.2.0 新增）

从左栏「协作 → AI 写作协作」进入，或在写作页工具条点 **AI 辅助**（自动带上当前章节）。

### 支持哪些模型来源

| 来源 | 默认地址 | 常用模型 | 备注 |
|---|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | deepseek-chat / deepseek-reasoner | OpenAI 兼容 |
| 腾讯混元 HY | `https://api.hunyuan.cloud.tencent.com/v1` | hunyuan-turbos-latest / hunyuan-pro | 需在腾讯云开通 |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | qwen-plus / qwen-max / qwen-long | DashScope 兼容模式 |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | qwen2.5:7b / llama3.1:8b | 离线；需设 `OLLAMA_ORIGINS=*` |
| 自建代理 / 其它 | 自己填（到 `/v1` 为止） | 任意 | one-api / new-api / LiteLLM / vLLM / 单位内网网关 |

**协议统一为 OpenAI 兼容**：凡实现 `POST {base}/chat/completions` 与 `GET {base}/models` 的服务都能直接接入，无需改代码。

### 五步配置

1. 选「模型来源」→ 自动填入默认地址与模型名（可改）。
2. 粘贴 API Key → 选「保存方式」→ 点 **保存密钥**。
3. 点 **测试连接**：成功会显示耗时与模型列表；失败会给出状态码与处置建议。
4. 在对话区上方选快捷动作（生成论证骨架 / 润色本节 / 审稿人质疑 / 过渡句 / 重写摘要 / 质疑提纲），或直接写要求。
5. 生成结束后点 **采用到章节** → 选目标章节与「追加 / 替换」→ 写入正文。

### 密钥怎么存（三档可选）

| 方式 | 存放位置 | 适用 |
|---|---|---|
| 口令加密保存（默认） | `localStorage` 密文（AES-GCM，PBKDF2 15 万次），每次打开需解锁 | 个人电脑，多人共用同一浏览器 |
| 仅本次会话 | `sessionStorage`，关标签页即失效 | 公用电脑、临时试用 |
| 明文保存 | `localStorage` 明文 | 仅在完全私人的机器上用，风险自负 |

- 口令不落盘，忘记后只能重填 Key。
- **API Key 不进项目 JSON**（单独键 `paperlab.aikey.v1`），分发备份不会泄露。
- 页面不会把 Key 写入对话内容或日志。

### 调用稳定性做了哪些处理

- 超时（默认 60 秒，可调）+ 停止按钮（AbortController）；
- 429 / 5xx 自动重试一次（仅当尚未输出任何内容时）；
- 流式（SSE）解析失败自动回退为整包 JSON；
- 空返回、401、403、404、413、429、5xx 分别给出可执行的排查建议；
- 上下文按需裁剪（章节 / 提纲 / 文献题录），并估算 token 数，避免超长；
- 保存最近一次测试结果与调用次数/耗时，便于判断是配置问题还是网络问题。

### 关于浏览器直连与 CORS（重要）

本程序是纯静态网页，请求由浏览器直接发往模型服务。**部分服务商的接口不允许浏览器跨域调用**，此时「测试连接」会提示「网络不通或被 CORS 拦截」。三种可行做法：

1. 用支持跨域的服务（本地 Ollama 设 `OLLAMA_ORIGINS=*` 即可）；
2. 自建网关（推荐）：one-api / new-api / LiteLLM 一台机器起好，地址填 `http://你的地址:端口/v1`，在网关侧统一管理各厂商 Key；
3. 公司内网通常已有统一网关，直接填其地址。

> 不要为了绕过跨域而在浏览器里关闭安全策略（如 `--disable-web-security`），那会同时暴露你的 Key 与本机数据。

### 常见错误对照

| 提示 | 多半原因 | 处理 |
|---|---|---|
| API Key 无效（401） | Key 复制不全/含空格/已吊销 | 重新粘贴，注意前后空格 |
| 地址或模型不存在（404） | 地址少了 `/v1`，或模型名拼错 | 按来源默认值核对 |
| 余额不足（402） | 账户欠费 | 充值或换来源 |
| 触发限流（429） | 频率/并发超限 | 稍后重试，降低 max_tokens |
| 网络不通或被 CORS 拦截 | 浏览器直连被拒 | 改用自建代理地址 |
| 模型返回为空 | 模型名不支持 / 内容被过滤 / max_tokens 太小 | 换模型或调大输出上限 |

## 四之三、文件导入（v0.3.0 新增）

三个入口：把文件拖到窗口任意位置；「项目总览 → 导入文献 / 正文」；「资料收集与管理 → 导入文件」或「正文写作」工具栏的「导入文档」。

| 文件类型 | 去向 | 解析方式 |
|---|---|---|
| `.bib` | 文献库 | 支持 `{…}` 与 `"…"` 两种取值、嵌套花括号；`author = {A and B}` 自动转逗号分隔 |
| `.ris` | 文献库 | CNKI、万方、Web of Science、Zotero 等导出的 RIS；读 `TY/TI/AU/JO/PY/VL/IS/SP/EP/DO/UR` |
| `.md` / `.markdown` | 正文 | 按 `#` / `##` / `###` 拆分章节，清理链接、强调、行内代码、引用块 |
| `.txt` | 正文 | UTF-8 优先，出现替换符时回退 GBK；识别「第 X 章 / 第 X 节 / 一、 / 1.1」分节 |
| `.docx` | 正文 | 浏览器内解压 zip 读 `word/document.xml`，按「标题 1/2/3」样式或大纲级别分节 |
| `.json` | 项目 | 覆盖导入（二次确认） |

正文导入弹窗会给识别字数、标题数、可并入章节数与前置段落数，并要求选择写入方式：

- **智能匹配**（默认）：标题与现有章节同名（去编号与空白后比较）或互相包含时并入，其余追加为新章节；
- **全部写入当前章节**；
- **按标题新建章节**：不并入现有章节，全部追加到提纲末尾；
- 勾选**覆盖已有正文**则替换匹配章节的内容，默认是追加。

限制：不读 `.doc`（旧二进制格式，请另存为 `.docx`）、`.pdf`、`.wps`；`.docx` 若没使用标题样式标记章节，会整篇当作一段；文献按题名归一化去重，同名条目会被跳过。

## 四之四、多标签同步（v0.3.0 新增）

同一浏览器开多个标签时，保存不再「后写覆盖前写」：

- 每个标签有独立 ID，每次写入把版本号记在 `paperlab.sync.v1`（与项目数据分开存放，不进项目 JSON 导出）；
- 另一标签保存后，本页若没有未落盘的改动、也没有正在编辑，会自动载入对方版本并提示，当前所在模块保持不变；
- 本页有改动（或光标停在编辑框、1.5 秒内输入过）时，底部弹出提示条，二选一：「载入对方版本」或「保留本页并覆盖」；
- 未选择前，本页的保存会被挂起（状态显示「待处理同步冲突」），避免静默丢数据。

已知边界：只解决同一浏览器内的覆盖问题，不做字段级合并——两份改动都要保留时需手动复制；不同浏览器、不同端口之间数据仍不互通。

## 五、数据存放与备份

| 项 | 说明 |
|---|---|
| 存储位置 | 浏览器 `localStorage`，键名 `paperlab.v1`，与访问地址绑定 |
| 备份 | 项目总览 → **导出项目 JSON**（含全部项目内容，不含界面偏好） |
| 恢复 | 项目总览 → **导入项目 JSON**（会覆盖当前项目，操作前有二次确认） |
| 风险 | 清理浏览器数据 / 换浏览器 / 换端口（端口变了地址就变，数据不共享）都会导致“看不到旧项目” |

> **重要**：更换端口或访问地址（如从 `8777` 改为 `9000`）相当于换了一个站点，`localStorage` 不互通。长期使用请固定端口，并定期导出 JSON 备份。

## 六、已知限制（v0.3.0）

试用时请按此清单判断“是缺陷还是待开发”：

1. **AI 需自备 Key 与网络**：不内置任何模型账号；浏览器直连可能被服务商 CORS 拦截（见上节）；AI 只给建议，写入正文必须手动「采用」。
2. **AI 不读全文**：上下文默认只带当前章节（≤4000 字）+ 提纲标题 + 前 20 条文献题录，避免超长与费用失控；不做整篇生成。
3. **导入不读旧格式**：`.doc`、`.pdf`、`.wps` 需先另存为 `.docx` 或 `.md`；`.docx` 依赖浏览器 `DecompressionStream`（Chrome/Edge 103+、Safari 16.4+、Firefox 113+），旧浏览器只能导入 `.md` / `.txt`。
4. **多标签同步不做合并**：只做「整份取舍」，两份改动都要保留时需手动复制；跨浏览器、跨端口仍不互通。
5. **无法静默导出 PDF**：走浏览器打印对话框，需手动选择“另存为 PDF”。
6. **无 DOCX 导出**：仅 Markdown / 独立 HTML / 纯文本 / 打印 PDF。
7. **查重为自查**：仅做 8 字窗口的自重复与跨章相似度提示，**不连接任何查重库**。
8. **引用格式为简化实现**：GB/T 7714 与作者-年制各一套规则，不覆盖全部文献类型细节。
9. **无跨设备协作**：无账号、无云端同步；同一浏览器内的多标签同步已支持。
10. **无移动端专项适配**：窄屏可滚动可用，但体验以桌面为主。

### 维护提示

- `serve.ps1` 内有中文提示文本，**编辑后必须保存为“UTF-8 带 BOM”**。Windows PowerShell 5.1 会把无 BOM 的 UTF-8 当成 ANSI(GBK) 读取，中文多字节字符可能吞掉或错位花括号，导致 `缺少右"}"` 之类的解析错误。
- `run.bat` 内有 `chcp 65001`，请保持 UTF-8 无 BOM 保存；加了 BOM 会让第一行 `@echo off` 失效。
- 若要改默认端口：同时改 `run.bat` 的 `set "PORT=..."` 与 `serve.ps1` 的 `-Port` 默认值（或只在 `run.bat` 里改，由它传入）。

## 八、EXE 版本说明（v0.2.0 起内置）

`善驮论文工坊.exe` 是自研的轻量启动器，不是把整个 Chromium 打包进去，因此只有约 15 KB：

| 项 | 说明 |
|---|---|
| 技术栈 | C# / WinForms / .NET Framework 4.8（Windows 10 1903+ 与 Win11 自带） |
| 依赖 | 无第三方 DLL，不需要 Node / Rust / Electron |
| 职责 | ① 起一个只监听 `127.0.0.1` 的静态文件服务器 ② 调用默认浏览器打开界面 ③ 托盘常驻与退出 |
| 安全 | 路径穿越防护（`../` 返回 403）、只绑定回环地址、不写注册表（安装版仅写 HKCU 卸载项）、不联网 |
| 限制 | 界面仍由系统浏览器渲染（不内嵌 WebView），所以“能否保存数据”取决于浏览器与地址，与网页版完全一致 |

**重新编译**（Windows 自带编译器，无需安装 SDK）：

```powershell
csc /nologo /target:winexe /optimize+ /out:善驮论文工坊.exe ^
    /r:System.Windows.Forms.dll /r:System.Drawing.dll src\launcher.cs
```

**支持的命令行参数**：`--no-browser`（只起服务，不开浏览器，便于脚本化测试）。

**关于 SmartScreen**：EXE 未做代码签名，首次运行可能提示「未知发布者」。点「更多信息 → 仍要运行」即可；如需在企业内分发，建议用单位证书签名并做哈希白名单。

**端口与数据**：数据绑定在 `http://127.0.0.1:8777`。若 8777 被别的程序占用，EXE 会退到 8778 等端口，此时旧的浏览器数据不会出现。处理办法：关掉占用 8777 的程序后重启善驮论文工坊，或用 JSON 备份迁移。

## 九、开源与反馈

- **许可证**：MIT，见 `LICENSE`。可自由使用、修改、二次分发，保留版权声明即可。
- **提 Issue**：使用「Bug 报告」或「功能建议」模板，写清环境、版本与复现步骤；不要粘贴完整的个人论文，用少量示例片段代替。
- **提 PR**：先读 `CONTRIBUTING.md`，两条硬约束——零第三方前端依赖、`localStorage` 键名与数据结构保持兼容。
- **代码地图**：`js/` 前端模块（`data` 字典 / `core` 内核 / `check` 检查引擎 / `ai` 接入层 / `views-*` 界面 / `app` 路由），`assets/styles.css` 全部样式，`serve.ps1` 本地服务，`src/launcher.cs` EXE 源码，`install.*` 与 `uninstall.*` 安装器。
- **发布**：每个版本把整包 zip 与 `善驮论文工坊.exe` 挂到 Releases，非开发者下载即用。
- **CI**：推送到 `main` 或提 PR 时，GitHub Actions 会检查必需文件、页面资源引用、JS 语法与 PowerShell 语法。
